OMORI Translation Installer — VN Revival

Extract the complete ZIP before opening OMORI Translation Installer.exe.
Keep the Resources folder beside the EXE. No Python, Node or PowerShell setup is needed.
Close OMORI, choose a language, and click Install. If OMORI is not found, choose
its Windows game folder. After installation, click Launch game (Steam).
Reopen this app to change the language while the game is closed.
Originals and recovery data stay in .vnrevival-omori inside the game's resource folder.
Do not remove that folder while a translation is installed.
For the release version, supported languages and checksum, see the OMORI page at
https://vnrevival.fun/ru/games/omori
